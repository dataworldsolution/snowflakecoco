6. Identified Gaps

GAP-01 No historical records / SCD versioning. All files use SCD Type 2 date columns (effective_start_date, effective_end_date, is_active), but no expired or historical rows exist. If tax rates or country attributes change, there is no mechanism to track the previous state.
GAP-02 No updated_at column. All files have created_at but lack an updated_at or last_modified_at timestamp. This makes it impossible to determine when a record was last changed without comparing snapshots.
GAP-03 Unused currencies in currency_master. 27 currencies exist but only 20 are referenced by the 35 countries (EUR is shared by 8). The 7 unreferenced currencies represent either future provisioning or orphan data. Verify if all 27 are intentional.
GAP-04 UK country code is non-standard. country_code = 'UK' is used instead of the ISO 3166-1 alpha-2 standard 'GB'. While iso_alpha3 = 'GBR' is correct, the 2-letter code deviates from the ISO standard. This may cause integration issues with systems that expect ISO-compliant codes.
GAP-05 No exchange rate data. The currency_master table contains static currency metadata but no exchange rates. Financial calculations that span currencies will need a separate FX rate source.
GAP-06 Single tax code per country. The 1:1 mapping between country and tax code does not accommodate countries with multiple tax regimes (e.g., US state-level sales tax, Canada provincial HST/PST, India state-level GST). The current model assumes a single national rate per country.
